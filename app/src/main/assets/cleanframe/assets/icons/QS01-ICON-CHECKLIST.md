# QS01 launcher icon checklist

Source catalog: [Simple Icons `develop/icons`](https://github.com/simple-icons/simple-icons/tree/develop/icons), pinned to commit `32e030086fdc605196391aab28519b14dc4295b4`.

The list covers launchable packages discovered on the QS01 in the Leanback and standard launcher categories.

## Suitable Simple Icons found

- [x] YouTube (`com.google.android.youtube.tv`) — `youtube.svg`
- [x] Plex (`com.plexapp.android`) — `plex.svg`
- [x] Google Play Store (`com.android.vending`) — `googleplay.svg`
- [x] iMirror / eAirPlay (`com.ecloud.eairplay`) — `airplayvideo.svg` (AirPlay video function mark)
- [x] Bluetooth Controller (`com.inspur.BlueToothController`) — `bluetooth.svg` (Bluetooth function mark)

## No suitable Simple Icon found

- [ ] Google Play Games (`com.google.android.play.games`) — no game-specific icon; Google Play is not a suitable substitute.
- [ ] BenQ Dashboard (`com.benq.dashboard`) — no BenQ icon in the catalog.
- [ ] Downloader (`com.esaba.downloader`) — no matching app icon.
- [ ] Cannoli / Scorza (`dev.cannoli.scorza`) — no matching icon.
- [ ] EShare (`com.ecloud.eshare.server`) — no matching icon.
- [ ] Gallery (`com.android.gallery3d`) — no matching generic gallery icon; Google Photos is not a suitable substitute.

System Settings launchers are excluded; they should use CleanFrame's generic Settings symbol rather than a brand mark.
